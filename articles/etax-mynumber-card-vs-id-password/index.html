e-Taxのマイナンバーカード方式とID・パスワード方式の違い｜新規発行停止と利用終了予定

公開日（サイト原稿）：2026-11-27　記述の基準日：2026-11-27

広告（PR / #ad）について。本記事には確定申告ソフトの広告（アフィリエイト）リンクが含まれます（該当箇所に「広告」と表示）。リンク経由で申し込みがあった場合、運営者が紹介料を受け取ることがあります。推奨ではありません。e-Taxの手続や申告の受理は保証しません。最新の取扱いは国税庁・e-Taxの公式案内で確認してください。

e-Tax（国税電子申告・納税システム）で所得税の確定申告書や申請・届出書を送信する際の認証方法には、主に「マイナンバーカード方式」と「ID・パスワード方式」があります。しかし、国税庁はID・パスワード方式で使うID・パスワードの新規発行を令和7年10月1日から停止しており、e-Taxのよくある質問では「令和9年分確定申告からは利用できなくなる予定」と案内しています。

本記事では、国税庁およびe-Taxの公式FAQ・案内PDFに基づき、両方式の具体的な違いと、すでにID・パスワード方式の届出をしている場合の取扱いを整理します。スマートフォンとマイナポータル連携を使った実際の送信手順については、【令和8年分】マイナポータル連携×e-Taxでスマホ確定申告をする準備と送信手順 を参照してください。

1. マイナンバーカード方式とID・パスワード方式の比較一覧

国税庁およびe-Taxの公式案内（e-Tax「マイナンバーカード方式について」、e-Tax「ID・パスワード方式とは何ですか。」、e-Tax利用の簡便化について教えてください。、国税庁「ID・パスワードの新規発行停止について」（PDF））に基づく両方式の主な違いは以下の通りです。

比較項目 マイナンバーカード方式 ID・パスワード方式
認証に使うもの マイナンバーカード（またはスマートフォンのマイナンバーカード）と、利用者証明用電子証明書のパスワード（数字4桁）・署名用電子証明書のパスワード（英数字6〜16文字） 「ID・パスワード方式の届出完了通知」に記載されたe-Tax用のID・パスワード（税務署が本人確認をしたうえで発行）
必要な機器 マイナンバーカードを読み取れるスマートフォン、またはパソコン＋ICカードリーダライタ（e-Taxソフト（WEB版）では、スマートフォンでQRコードを読み取ってログインする方法も案内されています） マイナンバーカードとICカードリーダライタは不要
新規利用の可否 利用できる 新規発行は停止（令和7年10月1日から）
今後の予定 国税庁が今後初めてe-Taxを使う人に案内している方式 令和9年分確定申告からは利用できなくなる予定
使える範囲 確定申告書等作成コーナー、e-Taxソフト（WEB版など）、マイナポータル連携 確定申告書等作成コーナーでのみ利用できる。メッセージボックスの閲覧には原則として電子証明書が必要

2. マイナンバーカード方式の特徴と必要なもの

マイナンバーカード方式は、マイナンバーカードに組み込まれたICチップの電子証明書を利用してe-Taxにログインする方式です（e-Tax「マイナンバーカード方式について」）。

必要なもの

  1. マイナンバーカード カード本体に加え、発行時に設定した以下の2種類のパスワードが必要です。 * 利用者証明用電子証明書のパスワード（数字4桁、3回連続で間違えるとロック）：e-Taxへのログインに使います。 * 署名用電子証明書のパスワード（英数字6〜16文字、5回連続で間違えるとロック）：申告等データへの電子署名に使います。 ※e-Taxの案内では、マイナンバーカードの電子証明書の有効期限は5年間とされ、失効した場合は市区町村の窓口で更新すればe-Taxを利用できるとされています（e-Tax「マイナンバーカード方式について」）（更新手続きは マイナンバーカードの電子証明書の更新 を参照）。

  2. 読取機器（スマートフォンまたはICカードリーダライタ） * スマートフォンで申告する場合：マイナンバーカードの読み取りに対応したスマートフォンと「マイナポータルアプリ」を使用します（国税庁「令和８年分の確定申告はスマホとマイナポータル連携でもっと便利に！」）。 * パソコンで申告する場合：ICカードリーダライタで読み取る方法のほか、e-Taxソフト（WEB版）のログイン画面で「スマートフォンを利用」を選び、マイナポータルアプリでQRコードを読み取る方法が案内されています（e-Tax「マイナンバーカード方式について」）。

マイナンバーカード方式のメリット（マイナポータル連携）

マイナンバーカード方式を利用すると、国税庁の「マイナポータル連携」機能（国税庁「マイナポータル連携特設ページ」）が使えます。給与所得の源泉徴収票や控除証明書等のデータをマイナポータル経由で取得して、申告書に反映できる機能です。所得税の確定申告では、マイナンバーカードを利用してe-Taxで提出する場合に限り、確定申告書等作成コーナーで使えます（取得方法の詳細は マイナポータル連携で控除証明書を取得する方法 や ふるさと納税で確定申告が必要になるとき を参照）。

3. ID・パスワード方式の現状（新規発行停止と廃止予定の公式文言）

国税庁の案内では、ID・パスワード方式は「マイナンバーカードが普及するまでの暫定的な対応」として運用されてきた方式で、税務署が本人確認を行った上で発行するIDとパスワードを使います（国税庁「ID・パスワードの新規発行停止について」（PDF））。

公式に発表されている重要な変更点

国税庁のリーフレット（国税庁「ID・パスワードの新規発行停止について」（PDF））およびe-Taxのよくある質問（e-Tax「ID・パスワード方式とは何ですか。」）では、以下の2点が公式に明記されています。

  1. 令和7年10月1日からの新規発行停止 国税庁のPDFによると、令和7年10月1日から、今後新たにe-Taxで申告する方には「マイナンバーカード方式」を案内し、「ID・パスワード方式」で使うID・パスワードの新規発行を停止しています。e-Taxを使うための利用者識別番号（16桁）の新規取得やe-Taxへのログインは、引き続きできるとされています（国税庁「ID・パスワードの新規発行停止について」（PDF））。
  2. 令和9年分確定申告からの利用終了予定 e-Taxのよくある質問では、「ID・パスワード方式は、令和９年分確定申告からは利用できなくなる予定です」と書かれています（e-Tax「ID・パスワード方式とは何ですか。」）。

4. すでにID・パスワード方式を持っている場合の継続利用の範囲

国税庁のPDFでは、すでに「ID・パスワード方式」の届出をしている方は引き続き利用できるとされ、今後の対応は改めて案内する予定とされています（国税庁「ID・パスワードの新規発行停止について」（PDF））。ただし、e-Taxのよくある質問では令和9年分確定申告からは利用できなくなる予定とされています（e-Tax「ID・パスワード方式とは何ですか。」）。

また、次の点に注意してください。

  • 使える手続の範囲が限られる ID・パスワード方式は、国税庁ホームページの「確定申告書等作成コーナー」（国税庁「確定申告書等作成コーナー」）でのみ利用できます（e-Tax「ID・パスワード方式とは何ですか。」）。また、開業届や青色申告承認申請書を会計ソフトから電子申告する際の認証要件もソフトごとに確認が必要です（開業届と青色申告承認申請書をfreee・弥生で作る流れと、確定申告ソフト3社の料金、青色申告承認申請書の提出期限と手続ガイド）。
  • マイナポータル連携は利用できない 所得税の確定申告でマイナポータル連携を使えるのは、マイナンバーカードを利用してe-Taxで確定申告書を提出する場合に限られます（国税庁「マイナポータル連携特設ページ」）。
  • メッセージボックスの閲覧 ID・パスワード方式で申告書を送信した場合でも、e-Taxのメッセージボックスの閲覧には、原則としてマイナンバーカード等の電子証明書が必要です（e-Tax「ID・パスワード方式とは何ですか。」）。

5. これからe-Taxを始める人が取るべき準備手順

これから初めてe-Taxで確定申告や各種届出を行う場合は、ID・パスワード方式の新規発行が終了しているため、マイナンバーカード方式を準備します。

  1. マイナンバーカードの取得と電子証明書の確認 未取得の場合はマイナンバーカードを申請・取得します。すでに持っている場合は、カード券面の有効期限と、ICチップ内の電子証明書（利用者証明用・署名用）が有効期限内であるかを確認します。
  2. パスワード（4桁・6〜16桁）の確認 カード受取時に設定した数字4桁と英数字6〜16文字のパスワードを確認します。どちらかがロックされた場合は、JPKI暗証番号リセットアプリとコンビニ等のキオスク端末で初期化できると案内されています（e-Tax「マイナンバーカード方式について」）。
  3. 確定申告書等作成コーナーまたはマイナポータルからのアクセス 確定申告期には、国税庁の「確定申告特集」（国税庁「所得税の確定申告」）や「確定申告書等作成コーナー」（国税庁「【確定申告書等作成コーナー】-作成コーナートップ」）から、該当する年分の画面を選択して作成・送信を進めます。なお、申告する年分（令和8年分など）の公開時期に合わせて最新の作成コーナー画面を使用してください。具体的な操作ステップは 【令和8年分】マイナポータル連携×e-Taxでスマホ確定申告をする準備と送信手順 で確認できます。

よくある質問（FAQ）

Q1. 今から税務署に行けば、ID・パスワード方式を新規発行してもらえますか？ いいえ、新規発行はできません。国税庁の案内では、ID・パスワード方式で使うID・パスワードの新規発行は令和7年10月1日から停止されています（国税庁「ID・パスワードの新規発行停止について」（PDF）、e-Tax「ID・パスワード方式とは何ですか。」）。これから新しくe-Taxを利用する場合は、マイナンバーカード方式を利用してください。

Q2. 以前作ったID・パスワード方式の通知書を持っています。令和8年分の確定申告でも使えますか？ すでにID・パスワード方式の届出をしている方は引き続き利用できるとされています。e-Taxのよくある質問では「令和9年分確定申告からは利用できなくなる予定」とされているため、令和8年分は確定申告書等作成コーナーで利用できる見込みです（国税庁「ID・パスワードの新規発行停止について」（PDF）、e-Tax「ID・パスワード方式とは何ですか。」）。今後の対応は改めて案内される予定のため、国税庁の最新の案内も確認してください。

Q3. パソコンでe-Taxを使う場合、ICカードリーダライタを買わないとマイナンバーカード方式は使えませんか？ ICカードリーダライタがなくても使える方法があります。e-Taxソフト（WEB版）のログイン画面で「スマートフォンを利用」を選ぶと、マイナポータルアプリでQRコードを読み取ってログインする方法が案内されています。スマートフォンだけで申告する方法もあります（e-Tax「マイナンバーカード方式について」、国税庁「令和８年分の確定申告はスマホとマイナポータル連携でもっと便利に！」）。
