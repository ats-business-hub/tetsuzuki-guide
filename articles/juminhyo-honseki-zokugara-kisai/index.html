住民票の写しの「本籍」「続柄」は記載すべき？省略の原則と請求時の選び方

公開日（サイト原稿）：2026-11-27　記述の基準日：2026-11-27

広告について。本記事には広告（アフィリエイト）リンクは含まれません。手数料・申請書の項目・記載の取扱いは市区町村で異なります。お住まいの市区町村と提出先の最新の案内で確認してください。

この記事の前提（基準日と対象範囲）

この記事は、住民基本台帳法の条文構造に関する自治体の案内、名古屋市・新宿区・渋谷区の住民票の写しの案内、J-LISのコンビニ交付の案内をもとにまとめています。公式ページは2026年11月27日に確認しました。手数料や申請書のチェック項目は市区町村で異なります。本記事に広告（アフィリエイト）リンクは含まれません。戸籍証明書の取り方は 戸籍証明書の広域交付とコンビニ交付、コンビニでの住民票は 住民票の写しをコンビニで取る方法 もご覧ください。

meta description 住民票の写しを請求する際に迷いやすい「本籍」「筆頭者」「世帯主・続柄」「マイナンバー」の記載有無について、住民基本台帳法に基づく省略の原則と提出先ごとの選び方を解説。窓口やコンビニ交付で選択する際の注意点も整理します。

就職・転職先への提出、運転免許証の手続き、パスポート申請、不動産の賃貸・売買契約など、さまざまな場面で求められる「住民票の写し」。いざ市区町村の窓口やコンビニエンスストアのマルチコピー機で請求しようとすると、「本籍・筆頭者を記載しますか？」「世帯主・続柄を記載しますか？」という選択画面が表示され、どちらを選ぶべきか迷うケースが少なくありません。

住民票の写しは、原則として個人のプライバシー保護の観点から「本籍・筆頭者」および「世帯主・続柄」が省略された状態で発行されます。これらを記載するかどうかは、提出先が求める要件に合わせて請求者自身が選択する必要があります（e-Gov法令検索（住民基本台帳法）、名古屋市「住民票の写し等・戸籍の附票の写し等の記載事項」、新宿区「住民票等の証明」、渋谷区「住民票の写しなどの請求」）。本記事では、記載事項の法的な位置づけ（省略の原則）と、提出目的別の選び方、請求時の注意点を解説します。

1. 住民票の写しにおける「省略の原則」とは

住民票の記載事項については、住民基本台帳法（昭和42年法律第81号）第7条に定められています（e-Gov法令検索（住民基本台帳法））。基本となる記載事項には、氏名、出生の年月日、男女の別、住所、住民となった年月日などが含まれますが、これらに加えて以下の項目も住民票に記録されています。

  1. 世帯主の氏名及び世帯主との続柄（住民基本台帳法第7条第4号）
  2. 戸籍の表示（住民基本台帳法第7条第5号。日本国籍を有する者の場合）。名古屋市などの案内では、これは本籍及び筆頭者の氏名を指すと説明されています。条文の見出しを「本籍及び筆頭者の氏名」と書き換えて引用はしていません。
  3. 個人番号（マイナンバー）（同法第7条第8号の2）
  4. 住民票コード（同法第7条第13号）

なぜ原則として省略されるのか

住民基本台帳法第12条第5項等の規定に基づき、住民票の写しの交付請求があった場合、市区町村長は「世帯主・続柄」および「本籍・筆頭者」の記載を省略して交付することが原則とされています。請求者から「記載を求める」旨の特別な申し出があった場合に限り、これらの項目が記載された住民票の写しが交付されます（e-Gov法令検索（住民基本台帳法））。同項は、特別の請求がない限り、第7条第4号、第5号および第8号の2から第14号までに掲げる事項の全部または一部の記載を省略した住民票の写しを交付することができる、と定めています。

これは、個人情報保護および差別防止等の観点から、提出先にとって不要な機微情報（本籍地や家族構成・続柄など）が第三者に過度に渡ることを防ぐための仕組みです。自治体の案内でも、特別の請求がない限りこれらの事項を省略するとされています（名古屋市「住民票の写し等・戸籍の附票の写し等の記載事項」、新宿区「住民票等の証明」、渋谷区「住民票の写しなどの請求」、総務省「住民票の写しの交付制度等の見直し」）。

また、個人番号（マイナンバー）や住民票コードについても同様に原則省略されており、法律や条例で定められた特定の事務（社会保障・税・災害対策の手続きなど）で提出先から明確に求められた場合のみ、記載を請求できます。マイナンバーの記載が必要かどうかは、提出先が法令上その記載を求めているかによります。名古屋市は、第三者による請求では個人番号と住民票コードを記載できないとしています。用途に迷う場合は、提出先と市区町村の案内を確認してください。名古屋市は、第三者による請求では個人番号と住民票コードを記載できないとしています（名古屋市「住民票の写し等・戸籍の附票の写し等の記載事項」）。

2. 【提出先別】本籍・続柄・マイナンバーの記載要否の目安

住民票の写しに記載する項目は、「提出先が指定する条件」に合わせるのが絶対のルールです。提出先から特に指定がない場合は、原則どおり「すべて省略（記載なし）」を選択するのが基本です（e-Gov法令検索（住民基本台帳法）、名古屋市「住民票の写し等・戸籍の附票の写し等の記載事項」）。

一般的な提出先ごとの傾向は以下の通りですが、実際の申請時には必ず提出先の案内書類や募集要項で最新の指定内容を確認してください。

主な提出先・手続きの例 本籍・筆頭者 世帯主・続柄 マイナンバー 備考・確認ポイント
勤務先（入社手続き・年末調整等） 原則 省略 提出先の指定による（扶養の手続などで記載を求める場合あり） 原則 省略（※番号収集は別方法が多い） 会社からの指示があればそれに従い、不要なら省略する
運転免許証（新規取得・記載事項変更等） 記載（本籍記載のものが必要） 原則 省略 省略（記載不可・不要） 免許申請・本籍変更等では本籍記載の住民票が必要（都道府県公安委員会の案内に従う）。渋谷区は、運転免許証の申請に添付するために本籍の記載が必要なときは請求書に明示するよう案内しています（渋谷区「住民票の写しなどの請求」）

不動産契約・住宅ローン・銀行口座開設 原則 省略 提出先の指定による（ペアローンなどで記載を求める場合あり） 省略（記載不可の機関が多い） 金融機関・不動産会社の指定要項に従う

※上記は一般的な傾向をまとめたものであり、個別の手続きや提出先の規定によって必要項目は異なります。「記載あり」で発行した住民票は、提出先によっては「不要な情報が載っているため受理できない（差し替えが必要）」となるケース（特にマイナンバー記載時や一部の企業提出時など）があるため、「迷ったら全部載せておけば安心」という選び方は避けてください。

なお、世帯全員分（謄本）か本人分のみ（抄本）かの選択も、提出先の指定（「世帯全員の住民票」か「本人のみの住民票」か）に合わせる必要があります。

3. 窓口・コンビニ交付での選び方（自治体事例）

実際に住民票の写しを請求する際の選択方法は、市区町村の窓口（郵送請求含む）とコンビニエンスストア等のマルチコピー機（コンビニ交付）で異なります。自治体によって申請書の様式や画面表示の細部が異なる場合があるため、以下では公表されている自治体の案内例をもとに手順を確認します。

市区町村の窓口・郵送で請求する場合

窓口備え付けの「住民票の写し等交付申請書」に記入する際、記載事項の選択欄（チェックボックスなど）で必要項目を指定します。

  • 名古屋市の例：窓口や郵送での請求時には、申請書上で「世帯主・続柄」「本籍・筆頭者」「個人番号（マイナンバー）」「住民票コード」それぞれの記載の有無を選択します。特に指定（チェック等）がない場合は、これらの項目が省略された住民票の写しが交付されます（名古屋市「住民票の写し等・戸籍の附票の写し等の記載事項」、名古屋市「請求に必要な書類〈住民票〉」）。
  • 新宿区の例：住民票の写しの請求にあたっては、本人確認書類の提示とともに、使用目的や提出先に応じた記載事項（「世帯主・続柄」「本籍・筆頭者」等の記載要否）を申請書に記入して手続きを行います（新宿区「住民票等の証明」）。
  • 渋谷区の例：窓口での請求時には、世帯全員分か一部（個人）かの別に加え、本籍・筆頭者、世帯主・続柄、マイナンバーなどの記載の有無を指定して申請します（渋谷区「住民票の写しなどの請求」）。

※申請書のチェック項目や手数料は市区町村で異なります。J-LISも、コンビニ交付の手数料は市区町村により異なるとしています（J-LIS「よくある質問（住民の方向け）」）。請求する前に、住んでいる市区町村の公式案内で確認してください。

コンビニ交付（マルチコピー機）で取得する場合

マイナンバーカードを利用してコンビニ等のマルチコピー機で住民票の写しを取得する場合も、操作画面の途中で記載事項を選択するステップが表示されます（総務省「コンビニ交付」、J-LIS「コンビニエンスストア等における証明書等の自動交付【コンビニ交付】」、渋谷区「コンビニエンスストア証明書自動交付サービス」）。

  1. 証明書の種類として「住民票の写し」を選択し、交付種別（「本人分のみ」または「世帯全員分」）を選びます。

  2. 続いて表示される「記載事項の選択」画面にて、以下の項目ごとに「記載する（有）」か「記載しない（無・省略）」を選択します。 * 世帯主・続柄 * 本籍・筆頭者 * 個人番号（マイナンバー）

  3. 画面の最終確認（発行内容の確認画面）で、選択した記載事項が意図通りになっているかを必ずチェックしてから手数料を投入し、印刷を実行します。

渋谷区のコンビニ交付案内では、世帯主名・世帯主との続柄・個人番号の記載を選択できること、日本人は本籍地・戸籍の筆頭者名の記載を選択できることが示されています（渋谷区「コンビニエンスストア証明書自動交付サービス」）。操作の大まかな流れは、キオスク端末のメニューから「行政サービス」を選び、画面の案内に従う、とされています（J-LIS「証明書の取得方法」、J-LIS「よくある質問（住民の方向け）」）。画面の表示文言や手順の細部は、店舗・自治体により異なる場合があります。

※記載事項の選択を誤ると、改めて交付を受ける必要が出ることがあります。確定操作の前に、本籍・続柄・個人番号の記載の有無を確認してください。返金や再印刷の取扱いは一律ではありません。J-LISは、印刷状態が悪い証明書をその場で店員に申告した場合の返金取扱いを案内しています（J-LIS「よくある質問（住民の方向け）」）。

コンビニ交付の具体的な操作手順や利用可能時間、対応店舗などの詳細は 住民票の写しをコンビニで取る方法 で詳しく解説しています。また、マイナンバーカードの電子証明書が期限切れの場合はコンビニ交付が利用できないため、事前に マイナンバーカードの電子証明書の更新 を確認しておくと安心です。渋谷区は、有効な利用者証明用電子証明書が付いたマイナンバーカードが必要で、利用時間は6時30分〜23時（保守等で利用できない場合あり）と案内しています（渋谷区「コンビニエンスストア証明書自動交付サービス」）。J-LISも、毎日6時30分から23時まで利用できる（市区町村により戸籍証明書等で異なる場合あり）としています（J-LIS「よくある質問（住民の方向け）」、総務省「コンビニ交付」）。

4. 請求・提出時に気をつけたい3つの注意点

1. 「マイナンバー記載」の住民票の取り扱い

マイナンバー（個人番号）が記載された住民票の写しは、番号法（行政手続における特定の個人を識別するための番号の利用等に関する法律）により利用範囲が厳格に制限されています。提出先から明確に「マイナンバー記載の住民票」と指定されていない限り、記載しない（省略する）を選択してください（名古屋市「住民票の写し等・戸籍の附票の写し等の記載事項」、新宿区「住民票等の証明」）。

2. 「住民票の写し」と「住民票のコピー」の違い

役所やコンビニで交付される正規の証明書そのものを「住民票の写し」と呼びます（自治体にある住民票の原本を写して公印を押したものという意味）。市区町村が交付した「住民票の写し」（公印のあるもの）と、それをコピー機で複写したものは別です。提出先が原本を求めることが多く、コピーでよいかは提出先の指定を確認してください。

3. 本籍地の確認だけなら別の方法もある

自分の本籍地がどこにあるか忘れてしまった場合、確認手段として「本籍記載の住民票の写し」を取得する方法が一般的です。なお、戸籍証明書そのものが必要な場合は、本籍地以外の市区町村窓口でも請求できる「広域交付制度」などの仕組みがありますが、利用条件や対象範囲が異なるため、戸籍の取得については 戸籍証明書の広域交付とコンビニ交付 を参照してください。

よくある質問（FAQ）

Q1. 提出先から「住民票を1通提出してください」とだけ言われ、本籍や続柄の指定がありません。どちらを選ぶべきですか？ A. 特に指定がない場合は、原則どおり「本籍・筆頭者」「世帯主・続柄」「マイナンバー」のいずれも省略（記載なし）を選んで問題ないケースが一般的です（e-Gov法令検索（住民基本台帳法）、名古屋市「住民票の写し等・戸籍の附票の写し等の記載事項」、新宿区「住民票等の証明」、渋谷区「住民票の写しなどの請求」）。ただし、提出後に差し替えになるのを防ぐため、念のため提出先の担当者や案内要項に指定がないか確認しておくと確実です。

Q2. 一度「本籍なし」で発行した住民票の写しに、後から本籍を追記してもらうことはできますか？ A. 発行済みの住民票の写しに、後から本籍や続柄などを追記してもらうとする公式の一律案内は見当たりません。記載を変えたい場合は、必要な事項を選び直して改めて交付を受けるよう案内する自治体があります。手数料は改めてかかります。

Q3. 外国籍の住民が住民票の写しを請求する場合、本籍の代わりに何が記載されますか？ A. 外国籍の住民（外国人住民）の住民票には「本籍・筆頭者」の欄はなく、代わりに「国籍・地域」や「在留資格」「在留期間等」「在留カード等の番号」などの事項が住民基本台帳法（第30条の45）に基づき記録されます（e-Gov法令検索（住民基本台帳法））。これらについても、請求時に記載の有無を選べる項目が設けられていることがあります。詳細は各市区町村の案内で確認してください（名古屋市「住民票の写し等・戸籍の附票の写し等の記載事項」、新宿区「住民票等の証明」、渋谷区「コンビニエンスストア証明書自動交付サービス」）。

Q4. 家族（同一世帯員）が窓口で本人の住民票を請求する場合でも、本籍やマイナンバー入りの住民票を受け取れますか？ A. 同一世帯員であれば、委任状なしで住民票の写しを請求できるとする案内が多くあります。一方、マイナンバー（個人番号）や住民票コードが記載された住民票の写しは、取扱いが厳しくなることがあります。新宿区の案内では、マイナンバー記載の住民票の写し等を本人とは別世帯の代理人が請求した場合、代理人に直接渡せないことがあり、その場合は本人の住民票の住所あてに転送不要の郵便で送付する、とされています（新宿区「住民票等の証明」）。具体的な運用は各市区町村の公式案内をご確認ください。
